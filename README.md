Please note! 

This repo, actually contains the code of the package available on [pypi](https://pypi.org/project/ofgrenudo/). Installing the app does nothing than give you a binary in your system path, to provide some fun information about me. If you interested in reading the source, you are welcome to view and fork this repository. Setting up the pypi package is a bit confusing, but once you get it done it works.
